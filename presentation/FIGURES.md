# Presentation figures

Generated by `presentation/make_figures.py` (charts) and
`presentation/make_figures_md.py` (this file). Regenerate both with:

```
.venv/bin/python presentation/corpus_stats.py     # recompute the funnel from data-vm/
.venv/bin/python presentation/token_stats.py      # recompute XLM-R token counts
.venv/bin/python presentation/model_stats.py      # recompute metrics from dumps + checkpoints
.venv/bin/python presentation/make_figures.py
.venv/bin/python presentation/make_figures_md.py
```

All PNGs are 300 dpi on a light background, sized for 16:9 slides.

## Where the numbers come from

| Source | Used for |
|---|---|
| `presentation/corpus_stats.json` | **Recomputed** from `data-vm/*/parsed/articles.jsonl`, replicating `classifier/build_dataset.py`'s filter order exactly. Figures 1, 2, 3. |
| `presentation/token_stats.json` | **Recomputed** with the `xlm-roberta-base` tokenizer over the same 383 articles `train_xlmr.py` loads. Figure 4. |
| `presentation/model_stats.json` | **Recomputed** from `humset_tfidf_cv.jsonl` and the four `xlmr_ckpt*.json` checkpoints, using `train_humset.prf`/`repair`/`MIN_SUPPORT`. No training. Figures 9, 11. |
| `classifier/data/humset_gold.jsonl` | Read directly. Figures 5, 6, 7, 8, 11. |
| round-2 labels (360 rows) | Read directly, filtered to `annotator == "HsuLinHtet"`. Figure 7. |
| `docs/WORKLOG.md` | **Transcribed**, only where the generating script is not in the repo: the learning curve (L1477-1480), the weak-supervision dose-response (L1602-1608), and the matched-input TF-IDF column (L1744-1756). Figures 8, 10, 11, and TF-IDF's 0.727 in figure 9. |

Every recomputed number was checked against the README and agrees. The one apparent conflict is explained below.

### The 38,009 vs 38,093 reconciliation

The README quotes both numbers and both are right -- they are different filters, and the figures use **38,009** throughout:

```
build_dataset.py   NFC-normalise + strip, then <200 drop, plus exact-body dedup -> 38,009
prelabel_llm.py    raw body length, no body dedup                               -> 38,093
difference         83 duplicate bodies + 1 article >=200 raw but <200 stripped = 84
```
38,009 is the model-ready corpus; 38,093 was only ever used for an API cost estimate.

### `fig12_annotation_ceiling.png`

**The ceiling set by annotation agreement**

50 gold articles re-labelled blind by a second annotator: exact set match 0.360, Jaccard 0.555 (mean per article, matching score_multilabel.py). Per-label F1 of the second annotator sits beside the model's. On Context and Casualties the model is AT the human level; on Shock/Event and Displacement it is above it. That is convention-learning, not competence: the model was fitted to these labels through CV and a second annotator was not, so the figure is captioned as a ceiling and explicitly NOT as a model beating a human. `other` and `information_communication` are excluded -- the second annotator had already seen all 85 pass-1 `other` articles, so no unseen sample can contain one. IAA run 1 is NOT plotted anywhere: it was served while the guide still named the under-represented labels and measures that priming (+23/-0 on humanitarian_access) rather than agreement.

*Numbers:* Agreement recomputed from classifier/data/annot-iaa2/; model F1 recomputed from the TF-IDF dump.

## Caveats worth repeating on the slides

1. **0.727, not 0.755.** XLM-R reads only the first 512 tokens, so the matched-input control is the comparison. Figure 9 says so in its subtitle.
2. **The thin labels are not measured.** 16 and 6 positives. Figures 5, 8 and 11 all mark them rather than reporting them as results.
3. **Round 2 is enriched, not representative.** Figure 7 and the table above say so.
4. **One annotator.** All 383 gold labels and all 360 round-2 labels come from a single annotator (pass 2 on 85 `other` articles was a second person). There is no inter-annotator agreement figure yet, so no figure claims reliability.
5. **Seed noise.** XLM-R per-label F1 carries roughly +-0.05; figure 11 shows error bars.
6. **Sep 2026 is partial.** Figure 3 annotates it.
